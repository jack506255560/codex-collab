# 0.8.0：专注企业微信

当前只支持企业微信，优先稳定接入、群收发、任务领取、代码交接与真人审核。其他 IM 的接入在企微流程稳定后再评估。

- 移除飞书适配器、群信息发现脚本、身份映射入口及 SDK；安装依赖减少 24 个包。
- 网页向导和 Peer 保持现有企微接入方式，同一项目多个机器人、个人接入包及已绑定 Codex 对话继续使用。
- 旧中心服务保留企微、HTTP/MCP、Git 任务账本和 Runner。新群任务与分配明确记录 `channel: "wecom"`；其他通道写入被拒绝。
- 历史任务保留原始来源。属于其他通道或缺少明确企微来源的任务仍可通过已授权 API 读取，不允许企微群查询或发送群通知。

## 升级

```sh
npm install --global xuym-codex-collab@0.8.0
codex-collab
```

现有 Peer 配置与业务仓库无需迁移。升级后重新启动本机工作台与已运行的机器人连接，使进程加载新版本；需要时在对应 Codex 对话重新连接 MCP。

从源码使用旧中心服务时，账号生成脚本只接受 `id:role:wecom_userid`，仅用 API 则填 `id:role:-`。旧四段参数会报错，避免身份错配。已有账号文件与个人令牌继续有效；补充企微身份可使用 `scripts/bind-wecom-users.mjs`，无需重新生成令牌。

本轮验证使用临时 Git 仓库、企微消息与 Codex mock，另检查 npm 安装和向导启动；不新增真实群或跨设备验收结论。
