# 0.10.0：让 Codex 组队工作

将已确认的星尘设计接入正式本机向导。首页说明两种协作方式：在企业微信群里连接自己的多个 Codex 会话，或与同事的 Codex 会话按角色分工、接力完成任务。

- 首页标题更新为“让 Codex 组队工作。”，桌面与移动端统一使用紧凑 Logo。
- 配色保留纸白、夜色；旧的雾绿选择自动回落到纸白。
- 增加 Three.js 星尘背景、轻微鼠标视差、星点牵引与短尾迹，移除鼠标光晕、手动停用按钮和背景说明文案。
- Three.js 固定版本，模块由本机向导提供，无需 CDN 或额外配置。背景不拦截点击，保留系统鼠标。
- 触屏与系统减少动态效果设置下使用静态星点，不创建 WebGL 上下文。无 WebGL 或上下文丢失时自动降级；页面隐藏时暂停动画。星点与尾迹各一次绘制，动画约 30 帧，像素比最多 1.5，画布最长边最多 2048 像素。

## 升级

```sh
npm install --global xuym-codex-collab@0.10.0
codex-collab setup
```

已有项目配置和协作记录无需迁移。升级后重启已运行的本机工作台进程，再打开向导，才能加载新代码；已有机器人连接按原有配置使用。

本次通过 216 项自动化测试，并在浏览器验证正式页面及临时目录安装后的 npm 包：项目归属、主题切换保留表单、320–3840 像素布局、后台暂停与恢复、触屏与减少动态效果、WebGL 降级与恢复均通过；安装后的 CLI 能启动独立工作台并提供完整背景资源。不新增真实企业微信群或跨机器验收结论。
