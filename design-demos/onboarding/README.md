# 轻引导与 Three.js 星尘 Demo

围绕“做几个简单动作就接入”的设计预览。单列居中，一屏一个重点；项目、机器人和连接状态全部使用示例数据，不会读写真实配置。星尘背景、鼠标跟随与首页文案已同步到正式向导。

从仓库根目录安装此 Demo 的独立依赖并启动：

```sh
npm install --prefix design-demos/onboarding
npm start --prefix design-demos/onboarding
```

在浏览器打开终端输出的 `DEMO_URL`。需要固定端口时可设置 `DEMO_PORT`，预览服务只监听本机。Node.js 版本要求与项目一致，为 20 或以上。

可以体验：

- 首页直接选择项目，或选择“接入一个项目 / 接受同事的邀请”。
- 进入项目查看机器人，只用“我的”标记归属；仓库信息按需展开。
- 接入项目：选择示例项目 → 确认企微机器人的两项信息 → 复制示例指令。
- 接受邀请：选择示例接入包 → 确认本机目录 → 复制示例指令。
- 完成后返回项目，或通过上一步调整输入；返回时保留已填内容。
- 固定使用星尘背景：星点有远近层次、柔和辉光与轻微视差；细圆环跟随鼠标，附近星点受到轻微牵引，移动时留下逐渐上浮、消散的星光尾迹。
- 页脚可切换纸白、夜色。切换配色保留当前步骤和输入，配色保存在地址栏，例如 `?theme=night#home`。旧的背景比较链接也会直接显示星尘。

点击选择文件夹、导入接入包与完成连接均为模拟交互。企微字段预填虚构的演示值；复制的指令明确标有“设计预览，请勿执行”。正式向导已接入目录选择、连接验证与对话绑定；此目录保留设计预览供对照。

步骤动效随操作发生：卡片依次出现、选中确认、步骤轻柔转场、连接信号与完成反馈，使用 CSS 和原生 Web Animations API。背景使用 Three.js 与自定义着色器：星点、尾迹各一次绘制，不使用全屏模糊或后期处理；最多 148 个背景星点和 44 个尾迹点，更新上限为每秒 30 帧，像素比最多 1.5，画布最长边最多 2048 像素。星点漂浮、引力、闪烁和尾迹消散均在着色器中完成。

Three.js 固定版本并从本地服务加载，不依赖 CDN；正式 npm 包通过运行依赖提供相同的本地模块。触屏与系统“减少动态效果”偏好下使用 CSS 静态星点，不创建 WebGL 上下文；没有 WebGL 或上下文丢失时也会显示静态星点。页面隐藏时暂停渲染，窗口缩放时调整画布。背景层不接收点击，不替换系统鼠标。

`previews/` 可保存本机生成的各页面与移动端截图；该目录不纳入版本控制。
