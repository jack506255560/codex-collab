# 0.10.6：接入向导自动填写与选项引导

接入向导优先自动填写，需要决定的内容提供选项，技术设置默认收起：

- 自动带入当前项目，提供本机已发现项目及原连接列表；其他项目和配置可浏览选择，无需手写路径。
- 自动识别远程仓库、业务基准分支和代码检查方式。优先使用项目已有测试，其次使用检查或构建；没有测试入口也可以继续接入。
- 无测试入口时使用基础改动检查，并在任务完成时检查起始提交到结果提交的差异。页面和任务结果明确提示：基础检查不代表功能测试通过，功能仍需人工审核。
- 名称已有默认值，职责提供中文选项，内部 Agent ID 自动生成；中文默认名称根据机器人身份生成稳定 ID，避免重新打开向导后发生冲突。
- 新增本人机器人、接受成员邀请时自动安排独立项目目录，邀请继承团队检查配置。
- 企业微信 Bot ID/Secret、邀请文件和密码旁说明获取位置；自定义命令、目录和身份设置仍可按需展开调整。

升级后重新打开向导，后台工作台会加载新版页面；已接入项目保留原检查配置。

```sh
npm install --global xuym-codex-collab@0.10.6 --prefer-online
codex-collab setup
```
