# 0.10.5：简化本机接入移除

移除本机协作接入现在是“查看影响 → 确认移除”两步：无需手动备份协作 Skill、输入 Agent 名称或先暂停轮询。自定义 Skill 会自动保存到本机恢复记录，恢复接入时可还原。

移除会解除这台电脑上的对话绑定并清理本机协作配置，不会删除 Codex 聊天、项目代码或其他机器上的配置。Git 已跟踪的共享配置、符号链接和有效任务租约仍会阻止自动移除，避免误改仓库或打断执行中的任务。

升级：

```sh
npm install --global xuym-codex-collab@0.10.5 --prefer-online
codex-collab setup
```
