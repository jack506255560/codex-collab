# Team collaboration

When working on an assigned collaboration task, read the task and latest handoff using the team's MCP tools before editing. Use a dedicated task worktree/branch. Record concise progress, test evidence and a commit/PR reference through the MCP tools. Never copy secrets or an entire private chat into Git. Follow the project's `.agents/skills/team-collab/SKILL.md`; if the MCP server is not installed or authenticated, say so rather than inventing task state.
