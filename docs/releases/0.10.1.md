# 0.10.1

修复升级 npm 包后重新打开向导时，旧后台服务仍被复用，导致星尘资源无法加载、页面样式不完整的问题。旧服务持有旧的路由表，却读取安装目录里更新后的 HTML，新增资源会返回 401 或 404。

- 后台服务记录启动时的软件版本、入口和 Node 路径。setup 在复用服务前检查这些信息；旧版本和未记录版本的服务会经过本机令牌验证，再正常退出并由新版替换。
- 并发执行多个 setup 会串行处理升级，同版本继续复用同一个服务。无法确认旧服务身份或旧服务未及时退出时停止升级，不强制结束进程。
- 服务切换保留项目配置、Codex 对话绑定、机器人运行意图和独立 Runner；打开向导时使用切换后的链接。

升级后运行：

```sh
npm install --global xuym-codex-collab@0.10.1 --prefer-online
codex-collab setup
```

回归覆盖旧服务迁移、版本不一致时替换、并发打开、同版本复用，以及无法验证身份时保留原进程；检查升级后的全部星尘与 Three.js 资源可访问，业务 API 仍要求登录。
