# 0.10.7：一次只做一步的接入向导

进一步简化机器人连接和 Codex 对话绑定，不改变现有服务端授权、签名审批或团队协议：

- 根据实际状态只突出一个下一步：缺少配置先修复，连接停止先启动，认证完成后再进入绑定；等待管理员确认时自动检查，不重复提交申请。
- 对话绑定分为“打开正确项目 → 复制指令到目标对话 → 等待真实轮询”。项目路径可独立复制，后台刷新保留当前指引步骤，切换机器人不串用进度。
- 错误显示在当前步骤，保留已保存的项目、身份与绑定，直接重试失败步骤。诊断失败项提供对应恢复入口，凭据变更仍先预览、再单独确认。
- 剪贴板不可用时提供手动复制内容；手动停止的连接不会自动重启。
- 只有观察到配置、机器人认证、真实绑定与最近轮询条件满足，才显示“连接已就绪”。复制指令或点击确认不代表成功，也不代表真实任务测试通过或保证未来自动唤醒。

升级后重新打开向导即可加载新页面，原项目、身份和绑定保留：

```sh
npm install --global xuym-codex-collab@0.10.7 --prefer-online
codex-collab setup
```

本版自动化和浏览器验证使用本机临时仓库与隔离示例服务；尚未完成真实企业微信、Codex 自动化和跨机器联合验收。
