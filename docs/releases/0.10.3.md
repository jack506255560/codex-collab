# 0.10.3：更清晰的首次使用引导

还没有接入项目时，向导首页直接显示两个入口：

- **我来发起协作**：接入代码项目，连接企业微信机器人，再邀请同事。
- **我来加入同事**：导入同事发来的邀请，接入已创建的项目。

此时收起空项目列表和重复的快捷按钮。从项目目录启动且检测到本机仓库时，首页会显示真实路径，并带入接入表单；不会覆盖用户尚未保存的目录选择。已有项目、待完成配置或旧版接入记录时，继续展示相应列表和快捷入口。

星尘背景的星点适度提亮，静态星点也同步调整。粒子数量和渲染流程保持不变，沿用夜色默认主题、触屏与减少动态效果下的静态显示。

升级：

```sh
npm install --global xuym-codex-collab@0.10.3 --prefer-online
codex-collab setup
```
