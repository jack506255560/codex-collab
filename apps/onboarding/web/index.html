把你的 Codex 带进群里。

一个机器人，一个会话，就可以开始。随时可以邀请同事一起协作。

  1. 选一个代码项目选择本机已有仓库，也可以从 Git 地址拉取。
  2. 连接企业微信机器人填入 Bot ID 和 Secret，再到群里发送验证码。
  3. 把启用指令发给目标会话在 Codex 打开该项目，将向导给出的指令发到你想绑定的会话。绑定并观察到轮询后，就能在群里 @ 机器人了。
已经接入过这个项目？打开项目中自己的机器人，继续绑定即可；想换一个会话，在“管理与重置”中选择重新绑定。
需要提前准备什么？

准备一个可访问远程的 Git 仓库、已加入企业微信群的 API 模式智能机器人，以及目标 Codex 会话。会话需按启用指令开启协作定时轮询，才能处理群消息；无需先邀请同事或设置多人分工。
