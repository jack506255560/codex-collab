# 0.5.0 · 简化接入和后台运行

日期：2026-10-22。

- 首页提供“连接我的机器人”和“接受同事邀请”两个入口；带入当前 Git 项目和本机名称，自动推荐验证命令；团队名称与内部 ID 收进更多设置。
- 输入邀请文件与密码后自动读取信息；成员默认自动拉取推荐目录，给自己增加机器人也支持自动创建独立 clone。
- 普通启动命令退出后工作台留在后台。macOS 默认设置 LaunchAgent，Linux 尝试设置 systemd 用户服务；不支持或注册失败时给出明确状态。保留前台排查与跳过自启选项。
- 后台只恢复已启用的机器人进程，失败后退避。持久化停止意图，串行处理跨进程启停，防止后台检查撤销用户的停止操作。迁移只接管仍运行的旧连接。
- 增加无需配置路径的 status/start/stop/doctor/repair、项目选择、自启管理与后台服务状态命令；旧显式路径兼容。
- 页面增加完整连接诊断与保守修复：真实进程、企微认证、绑定和轮询、Git 读写检查；恢复缺失的 MCP 配置和生成 Skill，自定义文件拒绝覆盖。

企业微信机器人创建、管理员入队批准、选择真实 Codex 对话并启用自动化仍需要本人操作。此版本不引入云端中转、不自动创建业务任务作连接测试。

验证详情见 `docs/onboarding-audit.md` 的 2026-10-22 条目。Windows 登录自启、真实重启登录、跨机器企业微信和 Codex 自动化联合验收仍需分别验证。
