# 轻引导 Demo

围绕“做几个简单动作就接入”的设计预览。单列居中，一屏一个重点；项目、机器人和连接状态全部使用示例数据，不会读写真实配置。

从仓库根目录启动，无需安装依赖：

```sh
node design-demos/onboarding/server.mjs
```

在浏览器打开终端输出的 `DEMO_URL`。需要固定端口时可设置 `DEMO_PORT`，预览服务只监听本机。Node.js 版本要求与项目一致，为 20 或以上。

可以体验：

- 首页直接选择项目，或选择“接入一个项目 / 接受同事的邀请”。
- 进入项目查看机器人，只用“我的”标记归属；仓库信息按需展开。
- 接入项目：选择示例项目 → 确认企微机器人的两项信息 → 复制示例指令。
- 接受邀请：选择示例接入包 → 确认本机目录 → 复制示例指令。
- 完成后返回项目，或通过上一步调整输入；返回时保留已填内容。
- 页脚可切换纸白、雾绿、夜色，页面结构一致；配色保存在地址栏。

点击选择文件夹、导入接入包与完成连接均为模拟交互。企微字段预填虚构的演示值；复制的指令明确标有“设计预览，请勿执行”。正式向导已接入目录选择、连接验证与对话绑定；此目录保留设计预览供对照。

动效随操作发生：卡片依次出现、选中确认、步骤轻柔转场、连接信号与完成反馈。使用 CSS 和原生 Web Animations API，仅对透明度、位移、旋转和缩放做动画。无需动画依赖、外部字体或远程资源；支持减少动态效果偏好，隐藏页面时暂停动画。

`previews/` 可保存本机生成的各页面与移动端截图；该目录不纳入版本控制。
